# Giphy React App

This project is a React application built with Vite that allows users to search and view GIFs using the Giphy API. The application includes features such as trending GIFs, category browsing, search functionality, and the ability to save favorite GIFs.

## Features

- **Trending GIFs**: View the latest trending GIFs.
- **Category Browsing**: Explore GIFs by categories.
- **Search**: Search for GIFs and stickers.
- **Favorites**: Save and view your favorite GIFs.
- **Responsive Design**: Optimized for both desktop and mobile devices.

## Technologies Used

- **React**: A JavaScript library for building user interfaces.
- **Vite**: A fast build tool and development server.
- **Tailwind CSS**: A utility-first CSS framework for styling.
- **Giphy API**: Fetch GIFs and related data.
